# Seratagna (ሰራተኛ) — Ethiopian Worker & Employer Platform

**Seratagna** is a lightweight, multilingual web application built to directly connect workers and employers across Bale Robe and all regions of Ethiopia. The platform allows employers to post job requests and enables job seekers to create verified profiles—eliminating unnecessary middleman fees.

---

## 🌟 Key Features

* **Direct Contact Capabilities:** Employers and job seekers can connect directly via standard phone calls or one-click WhatsApp messaging.
* **Multilingual Support:** Native language switching between **English**, **Amharic (አማርኛ)**, and **Afaan Oromoo**.
* **Categorized Worker Directory:** Search, filter, and browse profiles across key roles including Housekeepers, Drivers, Cooks, Security Guards, Construction Workers, and Caregivers.
* **Instant Requests & Registration:** Simple submission forms for both employers seeking workers and job seekers looking for employment.
* **Built-in Admin Panel:** Built-in dashboard protected by a passcode for administrators to review, verify, approve, or delete job postings and worker profiles.
* **Real-time Backend:** Powered by Supabase database integration for instant data persistence and updates.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox/Grid, Responsive Web Design), Vanilla JavaScript (ES6+)
* **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL with Row Level Security enabled)
* **Fonts & Icons:** Noto Sans Ethiopic, Segoe UI, Native Emoji Sets
